# perfectly-hooked

A responsive e-commerce website designed and developed for *Perfectly Hooked*, my crochet business, to provide customers with a smooth online shopping experience.

This project is my first frontend website and marks the beginning of my frontend development portfolio. It was built using HTML, CSS, and JavaScript, with a focus on responsive design, user experience, and solving real business needs.

# About the Project

Perfectly Hooked is a student-owned crochet business offering handmade crochet bags, accessories, earrings, bag charms and custom-made pieces.

As the business continued to grow, I saw the need for a structured online platform where customers could:

- Browse products
- Add multiple products to a shopping cart
- Make secure payments
- Place custom orders
- Easily contact the business

Instead of building a fictional portfolio project, I chose to solve a real-world problem by creating a functional e-commerce website for my own business.
